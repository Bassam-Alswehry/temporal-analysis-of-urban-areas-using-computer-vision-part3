# Temporal Analysis of Urban Areas — Part 3
## Decision Intelligence Dashboard (Power BI)

## Goal
Transform raw analytical outputs into clear, decision-oriented insights that support prioritization, risk assessment, and action planning.

## Key Outputs
- Decision overview charts summarizing change severity
- Priority vs Action matrix for executive decision-making
- Risk concentration analysis by area type
- Interactive filters for areas and decision categories

## Role in the Project
This part represents the **decision intelligence layer**, translating technical change detection (Part 1) and visual explanation (Part 2) into actionable insights for planners and decision-makers.

## Technologies
- Power BI
- Excel (data preparation)
